Codecraft is designed to make computer science learning feel more interactive and approachable for ESO students. It combines a playful, game-like presentation with educational content so lessons can be explored in a more engaging way than a standard classroom page.

Because it runs as a web project in HTML, Codecraft is easy to open in a browser and adapt to different learning environments. It is especially useful for teachers or students looking for a simple, visual way to present Informatica ESO topics with a familiar Minecraft-style atmosphere.
